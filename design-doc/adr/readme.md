# Architecture Decision Records (ADRs)

This directory contains the architectural decisions made for RazorConsole and the reasoning behind them. An ADR records **why an approach was chosen**; detailed implementation designs belong in separate documents when needed.

## Create an ADR

1. Copy [the template](template.md) into a new `.md` file (for example, `0001-rendering-strategy.md`).
2. Describe the problem, real options, supporting evidence, and decision. Use [the writing guide](guideline.md) for principles and review criteria.
3. Open a pull request to discuss the decision. Resolve any pending choice before merging.

Merging the PR means the decision is accepted. No separate status or date is required.

## Changing a decision

Do not overwrite an accepted ADR to change its rationale. Create a new ADR and add a visible **Superseded by** link to the old one. Keep both documents so future contributors can understand the history.
