# GallerySyntaxHighlighter

Standalone example extracted from the RazorConsole Gallery `SyntaxHighlighterGallery.razor` page.

This project keeps the Gallery preview as a runnable sample and intentionally omits the Gallery code-snippet panel.

## Run

```bash
dotnet run --project examples/GallerySyntaxHighlighter/GallerySyntaxHighlighter.csproj
```
