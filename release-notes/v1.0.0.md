# RazorConsole v1.0.0

**Unreleased — release date to be confirmed.** Draft started November 10, 2026.

RazorConsole 1.0.0 makes WidgetLayout the only rendering pipeline. Every frame is translated into widgets, laid out, and painted into terminal cells, so every element has known bounds for focus, mouse input, layout queries, and diagnostics. The legacy Spectre.Console layout pipeline, deprecated in 0.7.0, is removed.

These draft notes so far cover the legacy pipeline removal. Other changes since [v0.7.0](https://github.com/RazorConsole/RazorConsole/releases/tag/v0.7.0) will be added before publication.

## Highlights

- **One rendering pipeline:** the legacy Spectre pipeline, its `ITranslationMiddleware` translators, and the `RenderingPipeline` option are removed ([#474](https://github.com/RazorConsole/RazorConsole/pull/474)).
- **Everything takes part in layout:** FlexBox, Grid, inline HTML and Markdown text, charts, canvases, spinners, and syntax highlighting no longer fall back to whole Spectre subtrees. Nested components keep their layout bounds and receive coordinate-aware mouse events ([#471](https://github.com/RazorConsole/RazorConsole/pull/471)).
- **Custom widget translators:** the new `IWidgetTranslator` replaces `ITranslationMiddleware`. It runs for every node and returns widgets, and Spectre.Console content is returned as a `SpectreWidget` ([#472](https://github.com/RazorConsole/RazorConsole/pull/472)).

## Detailed Changes

### Rendering

- Render FlexBox with `FlexWidget` and Grid with a borderless `TableWidget`. Build charts, `SpectreCanvas`, `Spinner`, and `SyntaxHighlighter` as `SpectreWidget` leaves directly ([#471](https://github.com/RazorConsole/RazorConsole/pull/471)).
- Flow paragraphs and inline HTML elements (`strong`, `em`, `code`, `a`, `q`, and others) as one wrapped run with HTML whitespace collapsing. This fixes inline HTML rendering one element per line ([#471](https://github.com/RazorConsole/RazorConsole/pull/471)).
- Honor `FlexWrap.Wrap` in `FlexWidget` rows ([#471](https://github.com/RazorConsole/RazorConsole/pull/471)).
- Wrap table cell content that is wider than its column instead of cropping it ([#471](https://github.com/RazorConsole/RazorConsole/pull/471)).
- Keep the title row of a titled `Panel` or `Box` without a top border, like Spectre's `Panel` ([#471](https://github.com/RazorConsole/RazorConsole/pull/471)).
- Remove the unused VDOM-mutation path of the live display, which translated replaced nodes with the legacy pipeline on every diff ([#474](https://github.com/RazorConsole/RazorConsole/pull/474)).

### Extensibility

- Add `IWidgetTranslator`, `WidgetTranslationDelegate`, `AddWidgetTranslator<T>()`, and `AddWidgetTranslator(instance)`. Translators run in registration order before the built-in translation, and can decorate it by wrapping `next(node)` ([#472](https://github.com/RazorConsole/RazorConsole/pull/472)).
- Add `WidgetTranslationContext.TrackAnimation` for animated renderables placed in a `SpectreWidget` ([#472](https://github.com/RazorConsole/RazorConsole/pull/472)).

## Breaking Changes

- `RazorConsoleRenderingPipeline` and `ConsoleAppOptions.RenderingPipeline` are removed, and the `RAZORCONSOLE_RENDERING_PIPELINE` environment variable is no longer read ([#474](https://github.com/RazorConsole/RazorConsole/pull/474)).
- `ITranslationMiddleware`, `TranslationDelegate`, `TranslationContext`, `TranslationHelpers`, the built-in translator classes, `VdomSpectreTranslator`, and `SpectreRenderableFactory` are removed ([#474](https://github.com/RazorConsole/RazorConsole/pull/474)).
- `FlexBoxRenderable`, `BlockInlineRenderable`, `ScrollableRenderable`, `MeasuredAlign`, and `OverlayRenderable` are removed. The `FlexDirection`, `FlexJustify`, `FlexAlign`, and `FlexWrap` enums remain in `RazorConsole.Core.Renderables` ([#474](https://github.com/RazorConsole/RazorConsole/pull/474)).
- `WidgetTranslationContext` takes custom `IWidgetTranslator`s instead of Spectre fallback middlewares ([#471](https://github.com/RazorConsole/RazorConsole/pull/471), [#472](https://github.com/RazorConsole/RazorConsole/pull/472)).
- `ConsoleViewResult`, `ConsoleLiveDisplayContext`, `FocusManager.BeginSession`, and `FocusManager.FocusSession` are internal, and `ConsoleAppOptions.AfterRenderAsync` is removed. This keeps the renderer-to-terminal handoff out of the public API while terminal output moves to frames of cells ([#475](https://github.com/RazorConsole/RazorConsole/pull/475), [#425](https://github.com/RazorConsole/RazorConsole/issues/425)).
- `FlexJustify.SpaceBetween` with a single child places it at the start, as in CSS. The legacy FlexBox renderer centered it.
- The `RC_PRINT_VDOM_TREE` debug printer is removed. Use `razorconsole tree` and `razorconsole inspect` to read a running app's tree with layout.
- The diagnostics `screen` method no longer reports the `legacy_pipeline` reason, and `stats` always reports the `WidgetLayout` pipeline.

## Upgrade Notes

- Remove `ConsoleAppOptions.RenderingPipeline` assignments and the `RAZORCONSOLE_RENDERING_PIPELINE` environment variable.
- Move custom `ITranslationMiddleware` translators to `IWidgetTranslator`. Return `new SpectreWidget(node.ID, renderable, node.Key, node.Attributes)` where you returned a renderable, register with `services.AddWidgetTranslator<T>()`, and call `context.TrackAnimation` for animated content. See the [custom translator guide](/docs#custom-translators).
- If you used `ConsoleAppOptions.AfterRenderAsync`, move the work into a component's `OnAfterRenderAsync` or a hosted service.
- Review FlexBox, Grid, and inline HTML output: these now take part in layout, so sizes can differ slightly from the legacy Spectre renderables. See the [Widget Layout guide](/blog/widget-layout/).
