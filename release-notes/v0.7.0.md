# RazorConsole v0.7.0

**Unreleased — release date to be confirmed.** Draft prepared November 8, 2026. | [Milestone v0.7.0](https://github.com/RazorConsole/RazorConsole/milestone/8)

RazorConsole 0.7.0 adds a public testing package, a command-line tool and MCP server for driving terminal apps, and an official coding-agent plugin. It improves WidgetLayout rendering, overlays, tables, keyboard and mouse input, and introduces Tank Battle and Htop to the official app gallery.

These draft notes cover changes after [v0.6.0](https://github.com/RazorConsole/RazorConsole/releases/tag/v0.6.0), through [0579f4a](https://github.com/RazorConsole/RazorConsole/commit/0579f4a). The milestone was renamed from `v1.0.0` to `v0.7.0`; the version change does not remove its completed issues or pull requests. The notes also include merged changes outside the milestone. The final release tag and publication date are pending.

## Highlights

- **Test components and complete apps:** the new `RazorConsole.Testing` package provides `HeadlessTerminal` for in-process component tests and `PtyTerminal` for real application processes on Windows, Linux, and macOS, with input helpers, rendered frames, waits, and timeout diagnostics ([#384](https://github.com/RazorConsole/RazorConsole/pull/384)).
- **Drive apps from scripts and agents:** the new `RazorConsole.Cli` tool starts pseudoterminal sessions, sends input, inspects screens, and waits for or asserts on application state. `razorconsole mcp` exposes the same operations over stdio to MCP clients ([#422](https://github.com/RazorConsole/RazorConsole/pull/422), [#427](https://github.com/RazorConsole/RazorConsole/pull/427)).
- **Official agent plugin:** bundled skills guide app development, inspection, and testing, with an MCP configuration for the CLI server ([#430](https://github.com/RazorConsole/RazorConsole/pull/430)).
- **More reliable layouts and interaction:** fixes cover Markdown blocks, reordered `@key` children, absolute overlays, stale event handlers, pending focus requests, Enter activation, click propagation, and Windows Alt+Numpad text input.
- **New native apps and smoother animation:** Tank Battle and Htop join the official app gallery. Snake gains accumulating width traps and opts into synchronized terminal updates ([#361](https://github.com/RazorConsole/RazorConsole/pull/361), [#367](https://github.com/RazorConsole/RazorConsole/pull/367), [#381](https://github.com/RazorConsole/RazorConsole/pull/381)).

## Detailed Changes

### Components & Rendering

- Restore Markdown headings, syntax-highlighted fenced code, blockquotes, horizontal rules, and nested lists under WidgetLayout ([#364](https://github.com/RazorConsole/RazorConsole/pull/364)).
- Position absolute widgets against the document root or nearest absolute ancestor, paint overlays in z-index order, and center modals consistently. Update drag and tutorial samples that relied on the former parent-relative behavior ([#365](https://github.com/RazorConsole/RazorConsole/pull/365)).
- Make modals opaque, add `data-opaque` for other overlay containers, and preserve absolute positioning inside component wrappers and classless `Flex` containers ([#376](https://github.com/RazorConsole/RazorConsole/pull/376), [#412](https://github.com/RazorConsole/RazorConsole/pull/412), [#413](https://github.com/RazorConsole/RazorConsole/pull/413)).
- Fix doubled brackets in `Markup`, exceptions when removing attributes, and stale visual ordering after reordering `@key` children ([#374](https://github.com/RazorConsole/RazorConsole/pull/374), [#375](https://github.com/RazorConsole/RazorConsole/pull/375), [#386](https://github.com/RazorConsole/RazorConsole/pull/386)).
- Keep fixed-width table columns fixed when expansion can be assigned to flexible columns. If every column has a fixed width, the existing expansion behavior remains ([#410](https://github.com/RazorConsole/RazorConsole/pull/410)).
- Add `data-selected-bg` and `data-selected-fg` on table rows to paint selection backgrounds and text colors within row borders ([#411](https://github.com/RazorConsole/RazorConsole/pull/411), [#444](https://github.com/RazorConsole/RazorConsole/pull/444)).
- Preserve palette colors in component color attributes, including table borders, scrollbars, charts, and selected-row backgrounds ([#442](https://github.com/RazorConsole/RazorConsole/pull/442)).
- Add opt-in `ConsoleLiveDisplayOptions.EnableSynchronizedUpdates` to bracket complete frames with terminal synchronized-update sequences (DEC mode 2026), reducing tearing on terminals that support them ([#381](https://github.com/RazorConsole/RazorConsole/pull/381)).
- Deprecate `RazorConsoleRenderingPipeline.LegacySpectre`, with an obsolete API warning and one runtime warning per renderer. The pipeline remains available for compatibility; its documented removal is planned for v1.1.0 ([#379](https://github.com/RazorConsole/RazorConsole/pull/379)).

### Focus & Input Reliability

- Dispatch focus, keyboard, text input, and Enter-click events to the latest render of their target, including a bounded retry for stale handler IDs ([#394](https://github.com/RazorConsole/RazorConsole/pull/394)).
- Retain focus requests made before the focus session starts or before the requested element renders. Tab navigation cancels a pending request ([#395](https://github.com/RazorConsole/RazorConsole/pull/395)).
- Defer input dispatched from within renderer work until the current work finishes, preventing nested render batches from permanently duplicating elements. Add dispatcher serialization and continuation regression coverage ([#434](https://github.com/RazorConsole/RazorConsole/pull/434), [#415](https://github.com/RazorConsole/RazorConsole/pull/415)).
- Expose the read-only `TextInput.FocusKey` for use with `FocusManager.FocusAsync` ([#406](https://github.com/RazorConsole/RazorConsole/pull/406)).
- Forward unhandled keys through `Select.OnKeyDown` and `ViewHeightScrollable.OnKeyDown`. Add scrollbar `FocusOrder` and remove the scrollable root's extra Tab stop ([#387](https://github.com/RazorConsole/RazorConsole/pull/387), [#407](https://github.com/RazorConsole/RazorConsole/pull/407)).
- Send Enter activation only to the element that received the keydown, even when its handler moves focus ([#408](https://github.com/RazorConsole/RazorConsole/pull/408)).
- Honor Razor's `@onclick:stopPropagation` for mouse clicks, and hit-test absolute children that extend outside their parent's bounds ([#409](https://github.com/RazorConsole/RazorConsole/pull/409), [#439](https://github.com/RazorConsole/RazorConsole/pull/439)).
- Preserve characters entered through Windows Alt+Numpad sequences. Modifier-only key presses no longer emit `onkeydown` events on Windows; Alt with dedicated navigation keys remains supported ([#446](https://github.com/RazorConsole/RazorConsole/pull/446)).
- Make terminal-monitor disposal idempotent, avoiding an `ObjectDisposedException` during application shutdown ([#367](https://github.com/RazorConsole/RazorConsole/pull/367)).

### Testing, CLI & Agent Tools

- Publish `RazorConsole.Testing` without a dependency on a test framework. `HeadlessTerminal` exposes component frames, focus and layout; `PtyTerminal` runs real processes through ConPTY or POSIX PTYs and exposes parsed terminal state, output, and exit status. Its Core dependency is pinned to the exact matching package version ([#384](https://github.com/RazorConsole/RazorConsole/pull/384)).
- Await asynchronous service disposal in `HeadlessTerminal`, keep its newest render as the current frame, and fix a deadlock in observer-notification test synchronization ([#389](https://github.com/RazorConsole/RazorConsole/pull/389), [#417](https://github.com/RazorConsole/RazorConsole/pull/417), [#419](https://github.com/RazorConsole/RazorConsole/pull/419)).
- Add the `razorconsole` .NET tool and native executable: named sessions, keyboard/mouse/paste input, screenshots and frame diffs, waits and assertions, JSON output, and `doctor` diagnostics. App inspection includes element trees, focus, routes, errors, logs, and rendering statistics ([#422](https://github.com/RazorConsole/RazorConsole/pull/422)).
- Add `razorconsole mcp`, sharing the CLI session host and exposing session, input, screen, wait/assert, and app-inspection tools, plus session/screen/tree resources and layout/accessibility prompts ([#427](https://github.com/RazorConsole/RazorConsole/pull/427)).
- Add the official agent plugin with `razorconsole` and `razorconsole-inspect` skills and manifests for supported agent clients. The plugin keeps its separate `0.1.0` version; its MCP server requires the CLI on `PATH` ([#430](https://github.com/RazorConsole/RazorConsole/pull/430)).

See the [Testing guide](/blog/testing/), [CLI and MCP guide](/blog/cli/), and [agent plugin documentation](https://github.com/RazorConsole/RazorConsole/tree/main/plugins/razorconsole).

### Build & CI

- Reference the matching Blazor and Microsoft.Extensions major versions for `net9.0` and `net10.0`; `net8.0` retains 8.x and `net11.0` uses 10.x packages ([#431](https://github.com/RazorConsole/RazorConsole/pull/431)).
- Pin the repository SDK to `11.0.100-rc.3.26522.148` to resolve patched Native AOT compiler packages without suppressing NuGet Audit ([#450](https://github.com/RazorConsole/RazorConsole/pull/450)).
- Use NuGet trusted publishing for nightly and tagged builds ([#380](https://github.com/RazorConsole/RazorConsole/pull/380)).
- Use a fixed-width UTC timestamp in nightly version suffixes so builds with this format sort by build time, and retain the source commit as package metadata ([#451](https://github.com/RazorConsole/RazorConsole/pull/451)).
- Support GitHub merge-queue checks and pin website build jobs to Ubuntu 24.04 for browser-tool compatibility ([#426](https://github.com/RazorConsole/RazorConsole/pull/426), [#423](https://github.com/RazorConsole/RazorConsole/pull/423)).
- Migrate Python PTY checks to C# end-to-end tests on Windows, Linux, and macOS; run target-framework test modules sequentially to reduce overloaded-runner failures, and improve approval-test waits ([#384](https://github.com/RazorConsole/RazorConsole/pull/384), [#440](https://github.com/RazorConsole/RazorConsole/pull/440), [#391](https://github.com/RazorConsole/RazorConsole/pull/391)).

## Upgrade & Migration

**This release is being prepared.** The following commands select the intended stable versions once 0.7.0 is published:

```bash
dotnet add package RazorConsole.Core --version 0.7.0
dotnet add package RazorConsole.Testing --version 0.7.0
dotnet tool install --global RazorConsole.Cli --version 0.7.0
```

`RazorConsole.Testing` requires the exact matching Core version. Keep these packages aligned. The CLI tool requires .NET 8 or newer; its native executable needs no .NET runtime of its own, although managed applications it launches still do.

**If you installed a `1.0.0-alpha.*` nightly, explicitly select `0.7.0`.** NuGet considers `1.0.0-alpha.*` newer than `0.7.0`, and those existing nightly packages retain their original versions. An unconstrained update will not move you to 0.7.0. For an already installed CLI or Gallery .NET tool on the 1.0.0 nightly line, uninstall it and reinstall with `--version 0.7.0` after publication. New 0.7.0 nightlies also sort below the earlier 1.0.0 nightlies; pin the version when switching development lines.

WidgetLayout remains the default. Remove `LegacySpectre` option assignments and the `RAZORCONSOLE_RENDERING_PIPELINE` override to migrate from the deprecated pipeline. Spectre.Console-backed components, custom renderables, and fallback leaves remain supported. See the [Widget Layout guide](/blog/widget-layout/).

Review absolute layouts: `position="absolute"` now anchors to the document root or nearest absolute ancestor. `position="relative"` does not establish a containing block. Review Tab order in `ViewHeightScrollable`, and use its or `Select`'s `OnKeyDown` for shortcuts they do not handle internally.

CLI terminal commands can drive ordinary terminal programs. Element selectors and other app-inspection commands require a RazorConsole app with its diagnostics endpoint enabled; consult the [diagnostics conditions](/blog/cli/#when-the-endpoint-exists) when choosing the build and host environment.
